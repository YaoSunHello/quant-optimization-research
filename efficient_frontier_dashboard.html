📊 Efficient Frontier: VaR vs Cumulative Probability

2,000 random portfolios + 3 standard allocations
This visualization reveals the efficient frontier in a new coordinate system. Instead of Risk vs Return (traditional), we show Annualized VaR (downside risk) vs Cumulative Probability (average likelihood of beating multiple return targets). Each dot represents one portfolio. The color gradient (red → green) indicates how likely the portfolio is to achieve its targets. The three standard portfolios (Aggressive, Balanced, Conservative) are highlighted with larger markers, revealing their position on the frontier.

📌 How to Read This Chart:

• X-axis (Cumulative Probability): Average probability of beating return targets (0%, 5%, 10%, ... 30%). Higher = better odds across all thresholds.
• Y-axis (Annualized VaR): Worst expected return at 95% confidence, annualized. Higher (less negative) = safer downside.
• Color Gradient: Red (60-75% probability) → Orange → Yellow → Light Green → Dark Green (90%+ probability)
• Efficient Frontier: The upper-right boundary—portfolios that maximize probability for each VaR level.
• Key Insight: You cannot arbitrarily increase probability without accepting higher (less negative) VaR, just like you can't maximize return without taking risk.

💡 Key Takeaways

1. The Frontier Slope:

The efficient frontier is positively sloped: higher probability requires higher (less negative) VaR. This reflects the risk-return trade-off in new coordinates.

2. Red vs Green Dots:

Red dots (60-75% probability) are bond-heavy portfolios with high VaR but limited upside. Green dots (85%+ probability) are balanced/aggressive with good return odds.

3. Standard Portfolios:

Conservative sits far right (safest). Balanced is near the knee of the frontier (optimal risk-adjusted). Aggressive is left (highest probability of exceptional returns).

4. No Dominance:

No single portfolio dominates all others. The "best" depends on your risk tolerance and goals.
